# ChefMenuApp 🍽️

A React Native mobile application built for seamless restaurant menu management and course navigation.

---

## 📱 Features

- **Dynamic Menu Exploration:** Browse menu items organized cleanly by course categories.
- **Interactive Ordering:** Easily view, select, and manage food and beverage items.
- **Intuitive UI:** Minimalist and responsive design built for smooth mobile navigation.

---

## 🛠️ Tech Stack

- **Framework:** React Native (Expo)
- **Language:** JavaScript / JSX
- **Styling:** React Native StyleSheet
- **Tools:** Visual Studio Code, Git, GitHub

---

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and the Expo Go app installed on your mobile device.

- [Node.js](https://nodejs.org/) (v16 or higher)
- [Expo Go](https://expo.dev/client) on iOS or Android
